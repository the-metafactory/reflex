### Added
- **`reflex service … --instance <name> --config <path>`** (reflex#37): manages a named second service next to the default one: launchd label `ai.meta-factory.reflex.<name>` (systemd `reflex-<name>.service`), logs under `~/.config/reflex/logs/<name>/`, and `REFLEX_CONFIG` set to the absolute `--config` path in the unit. Names are allowlisted (`^[a-z0-9][a-z0-9-]{0,31}$`) and checked before any file or `launchctl` call; `install --instance` needs an existing, valid `--config` that sets `state_dir`. Without `--instance`, every verb and the rendered unit are unchanged (snapshot-tested).
- **`REFLEX_CONFIG` and `state_dir`** (reflex#36): the daemon and CLI read their config file from `REFLEX_CONFIG` when set (an explicit `configPath` option still wins; empty = unset), and the daemon opens `<state_dir>/reflex.db` when the config sets `state_dir` (leading `~/` expands), else the XDG default. A `REFLEX_CONFIG` naming a missing file fails startup naming the path, never falling back to env-only config. Lets a second instance run on one machine without sharing a config or DB. README documents a two-instance setup.
- **github-pr-review example blueprint**: an `http`-kind Activation Blueprint that fires when a PR is opened on a Metafactor repo (org-wide GitHub delivery, `github_hmac` auth) and targets `@jc/sage-pr-review` — the cortex F-6 bridge re-emits it as a CC-prompt dispatch running sage's existing `code-review.*` capability on the PR. The author trust gate (skip trusted authors, review everyone else) lives in cortex, NOT the blueprint: reflex's v0 `where` matcher is flat top-level field-equality with no nesting and no negation, so it can neither read `pull_request.user.login` nor express not-in. Reflex fires on every opened PR; cortex filters via a **configurable** trusted-author list applied **deterministically** by the bridge (dispatch dropped before any session starts — never an LLM "please skip"). See `examples/github-pr-review/reflex.yaml` (header documents the required `reflex_activation.targets` entry).
